# Miriyala R. C. Rushi — Developer Portfolio

A responsive personal developer portfolio built using semantic HTML5 and CSS3.

The portfolio showcases my learning journey and projects involving web development, Python programming, Linux, responsive design, Flexbox, and CSS Grid.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Media Queries
- Git & GitHub
- GitHub Pages

## Features

- Semantic HTML structure
- Responsive mobile-first design
- CSS colour and typography system
- Flexbox navigation
- CSS Grid project cards
- Responsive project layout
- Working email and GitHub links
- Mobile-friendly navigation
- GitHub Pages deployment

## Projects

### Responsive Card Gallery
A responsive card gallery created using HTML and CSS Grid with media queries.

### Roller-Coaster Gatekeeper
A Python program that evaluates age and height conditions and produces Boolean results.

### Chocolate Factory
A Python program that calculates complete chocolate boxes and leftover chocolates.

### Atlas Developer Workstation
A Linux terminal project demonstrating aliases, shell configuration, navigation, and command-line workflows.

### Tokenizer Exploration
An exploration of tokenization using different types of text inputs.

### Speed-Distance Calculator
A beginner Python program that calculates distance using speed and time.

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/miriyalarc26301058-hue/devfolio.git
```

2. Open the project folder:

```bash
cd devfolio
```

3. Open `index.html` in a web browser.

No additional dependencies or installation are required.
